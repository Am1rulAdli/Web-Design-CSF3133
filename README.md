# Hijayu Cafe

Browse the customer menu, build a pre-order, and reserve a table. The checkout is a visual assignment demo only; **no real payments are collected**.

## Visit the website

### [Open the Hijayu Cafe customer website](https://am1ruladli.github.io/Web-Design-CSF3133/)

The site opens directly to the customer experience. From there, you can browse the menu, adjust cart quantities, add notes to each item, reserve a table, and view the demo card or e-wallet checkout.

> **First-time setup:** If the link is not live yet, a repository owner needs to open **Settings → Pages**, select **GitHub Actions** as the build and deployment source, then run the **Deploy Hijayu Cafe to GitHub Pages** workflow from the **Actions** tab. GitHub will publish the site automatically.

## Project files

- [`customer.html`](customer.html) — customer menu, cart, and reservation experience.
- [`payment.html`](payment.html) — view-only demo checkout; does not collect card details or process payment.
- [`webdesign.html`](webdesign.html) — full project version, including the management portal.

## Run locally

Download or clone this repository, then open `customer.html` in a browser. The demo checkout opens automatically after confirming a reservation.
